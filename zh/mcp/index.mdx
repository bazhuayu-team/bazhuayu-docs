将八爪鱼采集能力接入 Coze（扣子）、Dify、QClaw（小龙虾）、ChatGPT、Claude、Cursor、Gemini 等兼容 MCP 的 AI 智能体。

八爪鱼 MCP 是面向 AI 智能体的**标准化数据连接器**。在对话中可以直接查询数据中心已经积累的存量内容，也可以搜索预置模板、触发云端采集、导出多种格式的数据，或按需采集 Temu、TikTok Shop 电商数据，无需手写爬虫代码。

截至 2026 年 8 月 28 日，八爪鱼采集器 MCP 主入口实测公开 **12 个工具**。服务端、模板和字段契约会持续更新；客户端实际可用能力应以连接后的工具发现结果与 `search_templates` 的精确查询结果为准。

## 前置条件

- **八爪鱼账户** — 免费版也可连接；免费 / 基础版用户每周可通过 MCP 获得 **2,000 条**免费采集额度
- **兼容 MCP 的客户端** — 见下方 [平台对接](#平台对接)，或 <a href="/zh/mcp/guides/clients" target="_blank" rel="noopener noreferrer">客户端配置指南</a>

## 让 Agent 自动添加（推荐）

WorkBuddy、QClaw、豆包专业版等具备工具配置能力的 Agent，通常可以根据一段对话自行添加 MCP 服务。先在账户中心<a href="/zh/mcp/quick-start/api-key" target="_blank" rel="noopener noreferrer">创建 API Key</a>，再将下面的内容发给 Agent，并把占位符替换为你的真实 Key：

```text
请帮我添加名为“八爪鱼”的 HTTP MCP 服务，并自行完成配置和连通性测试。

服务地址：https://mcp.bazhuayu.com
API Key：<粘贴你的 API Key>

关键要求：
1. 本次接入只使用 API Key 认证，请将密钥放在请求头 x-api-key 中。
2. 不要改用 OAuth，也不要写成 Authorization: Bearer <API Key>。
3. 请根据当前客户端支持的 MCP 配置方式自行安装；完成后按需刷新工具列表或重启客户端。
4. 请验证服务已连接并能读取工具列表，再调用只读工具 list_platforms 完成连通性测试；只向我报告配置位置、测试结果和后续用法，不要在回复中回显完整 API Key。
```

<Warning>
  仅在可信的本地 Agent 或私密对话中提供 API Key。不要把真实 Key 发送到群聊、公开对话或截图中；安装完成后也不要让 Agent 回显密钥。
</Warning>

八爪鱼采集器 MCP 使用 API Key 认证：将 Key 放入 `x-api-key` 请求头。若 Agent 无权修改配置，请按<a href="/zh/mcp/guides/clients" target="_blank" rel="noopener noreferrer">客户端配置指南</a>手动添加。

## 认证方式

使用请求头 `x-api-key` 认证。API Key 在<a href="/zh/mcp/quick-start/api-key" target="_blank" rel="noopener noreferrer">八爪鱼账户中心创建</a>；不要改写为 OAuth 或 `Authorization: Bearer <API Key>`。

<Warning>
  请勿将 API Key 写入公开仓库、截图或群聊。泄露后请立即在账户中心作废并重新创建。
</Warning>

## 按场景拆分数据任务

八爪鱼只提供一个 MCP 服务。为了让 Agent 更准确地选择工具，服务将完整的数据任务拆分为以下具体场景；它们不是三套彼此独立的产品，同一个业务任务可以组合使用多组工具。

| 场景 | Agent 要完成的任务 | 推荐工具 |
| --- | --- | --- |
| **直接查询已有内容** | 从数据中心检索提前采集的跨平台存量数据 | `list_platforms`、`search_platform_content` |
| **按需采集电商数据** | 提交 Temu、TikTok Shop 任务，确认结果集后查询 | `ecommerce_data_task`、`describe_ecommerce_dataset`、`query_collected_reviews` |
| **运行通用网站采集** | 选择模板、自动检查参数、查询状态并导出结果 | `search_templates`、`execute_task`、`get_task_status`、`export_data` |

例如，Agent 可以先从数据中心做跨平台检索，发现重点商品或网站后，再转入电商实时采集或模板化采集流程补充数据。

数据中心交付的是**提前采集的存量数据**：用户发起查询时直接检索已有内容，不必等待临时创建网页采集任务。一次于 2026 年 7 月 29 日进行的只读核验中，`list_platforms` 返回 **898 个平台条目**，映射到 **787 个去重域名**。这是当前可检索来源目录的规模口径，不是内容记录总数或固定服务承诺；同一域名可以对应多个产品入口或客户端形态，例如 `toutiao.com` 对应微头条、头条号、今日头条等多个条目。

目录覆盖社交社区、新闻资讯、财经证券、汽车、消费维权、招投标、政务公开资源和海外媒体等来源，数据形态包括网页、图片与视频。已核验的示例包括小红书、微信、微信视频号、知乎、豆瓣、百度贴吧、Facebook、人民网、新华网、腾讯新闻、东方财富网、雪球网、懂车帝、汽车之家、中国政府采购网、Reuters、Bloomberg、The Guardian 和 Yahoo! JAPAN。实际记录总量、可检索时间范围和平台目录都会持续变化；查询前应以 [`list_platforms`](/zh/mcp/list-platforms) 的实时返回为准。

## 通用采集工具

| 工具 | 说明 |
| --- | --- |
| `search_templates` | 搜索模板，并查看输入字段、输出字段与数据源选项 |
| `execute_task` | 自动检查参数，并创建及启动模板云采集任务 |
| `get_task_status` | 查询任务状态、采集批次号和已采集行数 |
| `export_data` | 按任务和批次号分页读取数据或获取签名下载链接 |
| `search_tasks` | 列出并搜索账户下已有任务 |
| `start_or_stop_task` | 按任务 ID 启动或停止云采集 |
| `redeem_coupon_code` | 兑换促销或资源优惠码 |

## 数据中心与电商数据工具

| 工具 | 说明 |
| --- | --- |
| `search_platform_content` | 按关键词、时间与站点条件搜索网页、图片和视频内容 |
| `list_platforms` | 查看数据中心内容搜索支持的平台代码 |
| `ecommerce_data_task` | 提交 Temu 或 TikTok Shop 关键词、详情或评论采集任务 |
| `describe_ecommerce_dataset` | 查看电商结果集的字段和稳定 ID 映射 |
| `query_collected_reviews` | 查询已采集的评论、商品详情或关键词搜索结果 |

各工具参数见侧栏 **通用采集工具** 和 **数据中心与电商数据** 分组。

## 快速开始

<Steps>
  <Step title="确认客户端支持 MCP">
    在 AI 产品中找到「MCP / 连接器 / 工具」配置入口。
  </Step>
  <Step title="让 Agent 添加或手动填写">
    优先将上方对话发送给支持自主配置的 Agent；也可以手动填写 `https://mcp.bazhuayu.com`（国际环境使用 `https://mcp.octoparse.com`）。

  <Step title="完成认证">
    在 Headers 中配置 <a href="/zh/mcp/quick-start/api-key" target="_blank" rel="noopener noreferrer">API Key</a> 的 `x-api-key`。
  </Step>
  <Step title="在对话中试用">
    先用只读请求验证连接，例如：「列出数据中心当前支持的平台」，或「帮我找一个采集电商商品列表的八爪鱼模板」。
  </Step>
</Steps>

## 示例工作流

完整流程见 <a href="/zh/mcp/workflow" target="_blank" rel="noopener noreferrer">工作流程示例</a>：

1. `search_templates` — 发现模板
2. 再次 `search_templates(id / slug)` — 读取本次运行的字段与选项
3. `execute_task` — 自动检查参数后启动云采集
4. `get_task_status` — 确认任务状态并获取 `lotNo`
5. `export_data` — 用 `taskId + lotNo` 分页读取或下载结果

## 使用实时工具契约

模板输入、数据源选项和电商结果集字段都可能随服务更新。建议每次任务都按以下原则处理：先精确读取模板或数据集契约，再传值；工具列表变化时，断开并重新连接或刷新客户端工具列表。不要把历史示例中的字段名、导出格式或旧工具数当作固定接口。
