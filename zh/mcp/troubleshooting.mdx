## 连接和认证

### 工具列表为空或不完整

**症状：** MCP 显示已连接，但没有工具，或未看到 `get_task_status`、`describe_ecommerce_dataset` 等当前工具。

**处理：**

- 确认 URL 为 `https://mcp.bazhuayu.com`；国际环境使用 `https://mcp.octoparse.com`。
- 确认 API Key 位于请求头 **`x-api-key`**，不要使用 OAuth 或 `Authorization: Bearer`。
- 断开后重新连接，刷新工具列表或重启客户端。
- 当前采集器 MCP 主入口实测有 12 个工具；不同客户端的展示名称可能不同，以工具标识和实时发现结果为准。

### API Key 无效

**症状：** `401 Unauthorized` 或 `403 Forbidden`。

**处理：**

- 按<a href="/zh/mcp/quick-start/api-key" target="_blank" rel="noopener noreferrer">获取 API Key</a>页面重新检查 Key 和 Header 名。
- 在八爪鱼账户中心重新生成 Key 后，仅更新私密客户端配置。
- 不要把真实 Key 写入仓库、截图或排障日志。

## 模板云采集

### 参数缺失或下拉选择无效

**症状：** `execute_task` 返回 `input_required`，或提示参数映射无效。

**处理：**

- 先用 `search_templates(query)` 发现模板，再用 `id` 或 `slug` 精确读取本次的 `inputSchema` 和 `sourceTree`。
- 参数 key 必须完全等于 `inputSchema[].field`，不要使用旧版 `field_2`、`url` 等别名。
- `MultiInput` / `CheckboxList` 即使只有一个值也传数组；下拉选项传 `sourceTree` 的 option `key`。
- 返回 `input_required` 时，按响应中的 `sourceOptions` 补齐依赖选择后再调用。

### 任务超时或不确定是否已创建

**症状：** `execute_task` 返回 `failed` 或连接中断，但响应中已经含有 `taskId`。

**处理：** 不要立即创建第二个任务。先调用 [`get_task_status`](/zh/mcp/get-task-status) 查询已有 `taskId`，确认 `running`、`completed`、`stopped` 或 `unexecuted` 后再决定下一步。

### 没有数据或无法导出

**症状：** 任务已创建，但导出结果为空或导出请求报参数错误。

**处理：**

- 用 `get_task_status` 等待任务 `completed` 或 `stopped`，并取得该次运行的 `lotNo`。
- `export_data` 必须传入 `taskId + lotNo`；分页参数是 `page` 与 `pageSize`，最大 `pageSize` 为 `100`。
- 大数据量优先使用返回的 `directAccess` 签名链接或 `curlTemplate`，不要重复将全部 JSON 传入对话。

## 数据中心和电商专项

### 无法限制数据中心搜索范围

**症状：** 不确定 `search_platform_content` 的站点包含或排除值。

**处理：** 先调用 `list_platforms`，使用本次返回的平台代码或站点标识配置包含、排除条件；不要根据展示名称或历史响应猜测域名字段。

### 电商任务提交后没有结果

**症状：** Temu 或 TikTok Shop 任务已提交，但 `query_collected_reviews` 暂时为空。

**处理：**

- 等待 `ecommerce_data_task` 响应中的 `resultAvailability.nextAvailableAt`。
- 使用 `nextStep` 返回的 `dataset` 与 `itemIds`。
- 先调用 [`describe_ecommerce_dataset`](/zh/mcp/describe-ecommerce-dataset) 核对字段和稳定 ID，再查询结果集。

## 获取帮助

仍无法解决时，请提供脱敏后的工具名、参数、完整错误信息或请求 ID，以及 MCP URL。不要提供真实 API Key 或短时签名下载 URL。
