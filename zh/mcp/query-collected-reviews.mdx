工具名称保留为 `query_collected_reviews`，但当前可查询的不只有评论，也包括商品详情和关键词搜索结果。该工具只读取已进入电商结果集的数据，不会启动新的采集任务。

## 查询前先确认数据集

可查询的数据集为：

- Temu：`temuComment`、`temuProductDetail`、`temuKeywordSearch`
- TikTok Shop：`tiktokShopComment`、`tiktokShopProductDetail`、`tiktokShopKeywordSearch`

优先使用 [`describe_ecommerce_dataset`](/zh/mcp/describe-ecommerce-dataset) 核对每个 `dataset` 的字段、稳定 item ID 字段和筛选提示，再传入 `dataset + itemIds` 查询。不要沿用历史页面或别的结果集中的字段名。

## 筛选与分页

查询可加入字段过滤、排序和分页；单页 `pageSize` 最大为 `100`。服务支持的过滤操作符包括：

`eq`、`neq`、`gt`、`gte`、`lt`、`lte`、`like`、`in`、`notin`

字段名必须来自 `describe_ecommerce_dataset` 的实时返回。刚提交采集时，应等待 `ecommerce_data_task` 响应中的 `resultAvailability.nextAvailableAt`；结果为空不一定表示任务失败。

## 推荐流程

```text
ecommerce_data_task
  → 读取 nextStep / resultAvailability
  → describe_ecommerce_dataset
  → query_collected_reviews
```

另请参阅：[`ecommerce_data_task`](/zh/mcp/ecommerce-data-task)、[`describe_ecommerce_dataset`](/zh/mcp/describe-ecommerce-dataset)
