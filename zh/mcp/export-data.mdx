---
title: export_data
description: 按任务和采集批次分页读取结果，或获取大结果集的签名下载链接。
---

在模板云采集完成或停止后，用 `taskId` 和 `lotNo` 调用 `export_data`。`lotNo` 是该次运行的采集批次号，应从 [`get_task_status`](/zh/mcp/get-task-status) 或 `execute_task` 结果中获取。

## 参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `taskId` | 是 | 任务 ID |
| `lotNo` | 是 | 本次采集的批次号 |
| `page` | 否 | 结果页码，默认 `1` |
| `pageSize` | 否 | 单页记录数，默认 `20`，最大 `100` |

```json
{
  "taskId": "<任务 ID>",
  "lotNo": "<采集批次号>",
  "page": 1,
  "pageSize": 20
}
```

## 响应与大数据导出

响应包含 `total`、`totalPages` 和当前页 `data`。请按 `totalPages` 继续分页，不要假定一页即可取得全部数据。

当结果量较大，尤其达到 50 条及以上时，服务可能返回 `directAccess`，其中包含：

- 短时有效的签名下载 URL；
- 可直接执行的 `curlTemplate`；
- 建议的输出文件路径。

大结果集优先使用 `directAccess` 下载，避免把大量 JSON 重复传入对话。签名链接具有时效性，也可能仅供当前授权范围使用，不要转发到公开渠道。

另请参阅：[`get_task_status`](/zh/mcp/get-task-status)、[`execute_task`](/zh/mcp/execute-task)
