`ecommerce_data_task` 是独立于模板云采集的电商专项入口。当前支持 Temu 和 TikTok Shop 的关键词搜索、商品详情和评论采集；不要将 Amazon 等其他电商平台按此工具调用。

## 选择采集类型

| `collectionType` | 适用输入 | 用途 |
| --- | --- | --- |
| `keywordSearch` | `keywords` | 按关键词发现商品 |
| `productDetail` | `productIds` | 查询商品详情；Temu 优先传商品 ID，必要时补充 URL 映射 |
| `reviews` | `productIds` | 提交商品评论采集 |

当前已确认的常用参数：

- `keywords`：关键词搜索输入。
- `productIds`：详情或评论采集的商品 ID。
- `site`：Temu 必填；TikTok Shop 当前默认美国站。
- `commentPages`：评论页数，范围 `1-50`，默认 `10`。
- `commentSort`：`default` 或 `time`，默认按时间。
- `keywordSort`：`default`、`sales`、`newest`、`priceAsc` 或 `priceDesc`。
- `limit` 与 `limitFlag`：控制结果数量或页数。

具体字段组合、站点可选值和必填规则会随采集类型变化。调用前请以客户端发现的实时 Schema 为准，缺少商品 ID 时不要把商品标题或任意 URL 当作 ID 填入。

## 异步查询结果

提交任务后不会保证立即有数据。响应中的 `nextStep` 会给出建议查询的 `dataset` 与 `itemIds`；等到 `resultAvailability.nextAvailableAt` 后：

1. 用 [`describe_ecommerce_dataset`](/zh/mcp/describe-ecommerce-dataset) 查看字段与稳定 ID 映射。
2. 再用 [`query_collected_reviews`](/zh/mcp/query-collected-reviews) 查询对应数据集。
