title: MCP 对接千问办公
description: 在千问办公中通过内置八爪鱼连接器完成 OAuth 授权并使用采集能力。
---

> 千问办公已经上架八爪鱼连接器。直接在连接器市场完成 OAuth 授权即可使用，无需手动填写 MCP 地址或 API Key。

## 前置准备

- 已登录千问办公
- 一个可以正常登录的八爪鱼账户
- 浏览器允许打开授权页面

<Note>
  本文介绍的是千问办公内置连接器，使用 OAuth 授权。只有手动添加通用 HTTP MCP 时，才需要配置 `https://mcp.bazhuayu.com` 和 `x-api-key`；不要把两种认证方式混用。
</Note>

## 连接八爪鱼

<Steps>
  <Step title="打开连接器并搜索八爪鱼">
    在千问办公中打开或新建任务，点击左侧导航中的「连接器」。在右上角搜索框输入「八爪鱼」，找到「数洞八爪鱼」连接器。

    <img src="/assets/mcp/qwen-office/step-1-find-connector.png" alt="在千问办公连接器市场搜索八爪鱼" className="mcp-step-image" />
  </Step>
  <Step title="发起连接">
    点击连接器卡片右侧的「+」或「连接」。千问办公会打开八爪鱼的 OAuth 授权页面。
  </Step>
  <Step title="确认并授权">
    核对应用名称、当前八爪鱼账户和授权范围，确认无误后点击「允许访问」或页面上的同义按钮。授权完成后按提示返回千问办公。
  </Step>
  <Step title="开始使用">
    确认连接器显示为已安装或已连接。回到任务对话，描述需要查询或采集的数据，千问办公会在需要时调用八爪鱼工具。
  </Step>
</Steps>

## 验证连接

建议先用不会创建任务的只读请求测试：

```text
请使用八爪鱼连接器，列出数据中心当前支持的平台。
```

如果能够返回平台列表，说明连接和授权已经生效。也可以继续让 Agent 搜索模板；运行采集任务前，请确认目标、参数和可能消耗的额度。

## 常见问题

| 现象 | 处理建议 |
| --- | --- |
| 搜索不到八爪鱼 | 刷新连接器市场，并确认使用的是支持连接器的千问办公版本；入口名称和上架范围可能随客户端更新而变化 |
| 点击连接后没有授权页面 | 检查浏览器弹窗拦截和网络设置，然后重新点击连接 |
| 授权后仍显示未连接 | 返回连接器页刷新状态；仍无效时断开后重新授权 |
| Agent 没有调用连接器 | 在当前任务中确认连接器已启用，并在请求中明确说明“使用八爪鱼连接器” |

<Note>
  客户端界面和按钮名称可能随版本调整，请以当前页面为准。授权时只在八爪鱼官方身份页面登录，不要把账号密码或 API Key 粘贴到对话中。
</Note>
