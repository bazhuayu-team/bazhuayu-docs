---
title: execute_task
description: 使用模板实时参数创建并启动八爪鱼云采集任务。
---

`execute_task` 会在创建任务前自动检查参数。参数缺失或下拉依赖未完成时，会返回可处理的问题而不创建任务；参数完整时才会启动云采集。

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `templateName` | string | 是 | 由 `search_templates` 精确查询返回的模板名称 |
| `parameters` | JSON 字符串 | 否 | key 必须严格等于 `inputSchema[].field` |
| `taskName` | string | 否 | 建议使用唯一名称，便于任务中断后恢复查询 |

```json
{
  "templateName": "<模板名称>",
  "taskName": "Amazon 商品采集-20260828",
  "parameters": "{\"搜索词\":[\"cup\"],\"亚马逊站点市场选择\":[\"DE\"],\"每项搜索的产品数量\":\"30\"}"
}
```

部分客户端会自动序列化对象；若服务提示参数类型错误，请显式传入 JSON 对象字符串。

## 参数检查与状态

- `Input` / `Dropdown` 传字符串；`MultiInput` / `CheckboxList` 始终传字符串数组。
- 数据源下拉字段必须传 `sourceTree` 中选项的 `key`。
- 返回 `input_required` 时，读取下一层 `sourceOptions`，补齐依赖选项后重新调用。
- 调用最长约等待 45 秒，常见结果为 `running`、`completed`、`stopped`、`failed` 或 `input_required`。
- 正常结果可能包含 `taskId`、`lotNo`、`collectedRows` 和任务里程碑。

若失败结果中已经包含 `taskId`，不要重建任务；先用 [`get_task_status`](/zh/mcp/get-task-status) 查询状态。

## 下一步

创建后用 `get_task_status(taskId)` 等待任务处于 `completed` 或 `stopped`，并记录返回的 `lotNo`。随后将 `taskId + lotNo` 传给 [`export_data`](/zh/mcp/export-data) 分页读取或下载结果。
