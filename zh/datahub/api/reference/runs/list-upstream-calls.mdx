## 端点

```
GET https://api-datahub.bazhuayu.com/v1/runs/{run_id}/upstream-calls
```

认证：需要 API Key，且仅 App 作者（发布者本人）可调用；其他人得到 `404`。

调试运行（`run_kind=test`）的上游调用时间线：api 型运行的每次上游 HTTP 交互（`submit` / `status` / `fetch`）各一条。`summary` 按（尝试次数，阶段）聚合整条留痕，与分页无关，一眼看出卡在哪个阶段；`items` 只含元信息，请求与响应体通过单条详情按需读取。

只能读自己的调试运行：别人的、不存在的、以及**生产运行**一律 `404`。凭证与环境项的值在写入时已打码；输入契约里标记 `sensitive` 的值读取时再打码一次。code 型运行没有 HTTP 留痕，返回空列表。

## 请求

### 路径参数

<ParamField path="run_id" type="string" required>
  调试运行的标识。
</ParamField>

### 查询参数

<ParamField query="offset" type="integer" default="0">
  分页起点。

范围 ≥ 0。
</ParamField>

<ParamField query="limit" type="integer" default="50">
  每页条数。

范围 1 到 500。
</ParamField>

<ParamField query="stage" type="string">
  只看某个阶段。`submit` 提交、`status` 轮询状态、`fetch` 取数。

取值：`submit` / `status` / `fetch`。
</ParamField>

### 示例请求

```bash
curl \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/runs/run_c62bc0fb8df2/upstream-calls"
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `upstream-calls-not-found` | `not_found` | 只有调试运行（`run_kind=test`）保留上游调用留痕；生产运行、他人的运行与不存在的运行都返回此错误。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误" target="_blank" rel="noopener noreferrer">错误</a>。
