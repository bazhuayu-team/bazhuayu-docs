## 端点

```
GET https://api-datahub.bazhuayu.com/v1/runs/{run_id}/upstream-calls/{call_id}
```

认证：需要 API Key，且仅 App 作者（发布者本人）可调用；其他人得到 `404`。

单条留痕的完整现场：请求（query / body）与响应体。响应体过大时在写入侧已截断，见 `response_truncated`。鉴权规则与列表端点相同。

## 请求

### 路径参数

<ParamField path="run_id" type="string" required>
  调试运行的标识。
</ParamField>

<ParamField path="call_id" type="integer" required>
  留痕条目标识，来自列表的 `items[].call_id`。
</ParamField>

### 示例请求

```bash
curl \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/runs/run_c62bc0fb8df2/upstream-calls/1"
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `upstream-calls-not-found` | `not_found` | 只有调试运行（`run_kind=test`）保留上游调用留痕；生产运行、他人的运行与不存在的运行都返回此错误。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误">错误</a>。
