authMethod: bearer

## 端点

```
POST https://api-datahub.bazhuayu.com/v1/runs/{run_id}/cancel
```

认证：需要 API Key（`Authorization: Bearer <API Key>`）。

下达取消信号并短暂等待（最多 5 秒）执行方响应，返回当前运行对象。排队中的运行立即停止；执行中的通常在数秒内协作停止。已经写回的记录保留（`partial` 为 `true`），可以照常读取，只按已产出的记录计费。

归属门与运行详情相同：只能取消自己发起的运行。取消后用查询运行确认终态。

## 请求

### 路径参数

<ParamField path="run_id" type="string" required>
  运行标识。
</ParamField>

### 示例请求

```bash
curl -X POST \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/runs/run_c62bc0fb8df2/cancel"
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `run-not-found` | `not_found` | 运行不存在，或不是当前账号发起的。 |
| 409 | `run-terminal` | `invalid_input` | 运行已经结束，无法取消。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误">错误</a>。
