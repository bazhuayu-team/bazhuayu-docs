## 端点

```
GET https://api-datahub.bazhuayu.com/v1/data-apps/{app_id}/manifest
```

认证：需要 API Key，且仅 App 作者（发布者本人）可调用；其他人得到 `404`。

作者读回**最新 Release** 的完整 manifest（含 `runtime` 块），是「编辑后重新发布」的数据源。零 Release 返回 `404`；草稿的自检一律走工作区端点，两者不混用。

`runtime` 是后端构件，从不出现在卡片、详情等公开载荷里，所以本端点仅作者可用。`auth.secret` 只是对 `runtime.env` 的别名引用，凭证明文只在密钥库，不随读回外泄。`status` 与 `scope` 按当前运营状态注入而不是 manifest 原值；manifest 不再携带 `identity.version`，版本号请从版本列表取。

## 请求

### 路径参数

<ParamField path="app_id" type="string" required>
  App 引用。
</ParamField>

### 示例请求

```bash
curl \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/data-apps/carol/reviews-query/manifest"
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `release-not-found` | `not_found` | 该版本不存在，或 App 尚无任何 Release。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误" target="_blank" rel="noopener noreferrer">错误</a>。
