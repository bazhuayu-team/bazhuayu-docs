---
title: "恢复维护"
description: "撤销弃用标记，状态回到原有轨道。"
---

**`POST`** `https://api-datahub.bazhuayu.com/v1/data-apps/{app_id}/undeprecate`

认证：需要 API Key，且仅 App 作者（发布者本人）可调用；其他人得到 `404`。

恢复维护（幂等）：清除弃用标记，派生状态回到原有轨道，有 Release 时重新为已发布（按可见范围恢复市场检索），没有则为草稿。

与版本级的撤回 / 撤销撤回同构：弃用是身份级标记，不是物理状态。恢复不会触碰可见范围与维护开关：作者在弃用期间切过的运营开关不会被静默切回。

## 请求

### 路径参数

<ParamField path="app_id" type="string" required>
  App 引用。
</ParamField>

### 示例请求

```bash
curl -X POST \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/data-apps/carol/reviews-query/undeprecate"
```
