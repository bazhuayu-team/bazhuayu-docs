## 端点

```
POST https://api-datahub.bazhuayu.com/v1/data-apps/batch/grants
```

认证：需要 API Key（`Authorization: Bearer <API Key>`）。

一次向多个用户开放多个你拥有的 App（矩阵语义，幂等）。存储与生效规则与单用户授权相同。每个用户名只解析一次。`granted` 只计**新增**的配对，已在名单上的配对幂等跳过，便于区分「新增 3 个、已有 2 个」。

<ParamField body="app_names" type="string[]" required>
  —

### 示例请求

```bash
curl -X POST \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"apps": ["carol/reviews-query", "carol/product-detail"], "usernames": ["dave", "erin"]}' \
  "https://api-datahub.bazhuayu.com/v1/data-apps/batch/grants"
```
