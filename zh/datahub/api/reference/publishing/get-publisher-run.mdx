---

**`GET`** `https://api-datahub.bazhuayu.com/v1/publisher/runs/{run_id}`

认证：需要 API Key（`Authorization: Bearer <API Key>`）。

对我发布的 App 的一次调用，与列表相同的白名单字段，外加该运行的结构化告警（如 `billing-qty-missing`）。归属按 **App**：他人 App 的运行与不存在的 `run_id` 都返回 `404`。这里没有 `input`、没有结果数据、没有调用方身份；除非你自己也是发起人，否则这个 `run_id` 无法在自己的运行列表里打开。

## 请求

### 路径参数

<ParamField path="run_id" type="string" required>
  运行标识。
</ParamField>

### 示例请求

```bash
curl \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/publisher/runs/run_c62bc0fb8df2"
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `run-not-found` | `not_found` | 运行不存在，或不是当前账号发起的。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误">错误</a>。
