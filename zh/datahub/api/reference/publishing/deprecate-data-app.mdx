## 端点

```
POST https://api-datahub.bazhuayu.com/v1/data-apps/{app_id}/deprecate
```

认证：需要 API Key，且仅 App 作者（发布者本人）可调用；其他人得到 `404`。

身份级弃用（幂等、可逆）：不再维护、建议迁移、拒绝新的 Release。

弃用的 App 退出市场检索，但详情按可见范围仍可读，运行仍被允许。切断供给是作者的明确决定（维护开关），不是弃用的隐含语义，这样进行中的集成不会突然中断。零 Release 的 App 也可以弃用。误操作或改变主意可通过恢复维护撤销。

## 请求

### 路径参数

<ParamField path="app_id" type="string" required>
  App 引用。
</ParamField>

### 示例请求

```bash
curl -X POST \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/data-apps/carol/reviews-query/deprecate"
```
