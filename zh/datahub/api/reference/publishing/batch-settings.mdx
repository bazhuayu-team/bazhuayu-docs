---
title: "批量调整运营设置"
description: "把同一份设置补丁应用到多个 App，用于整簇暂停或恢复。"
---

**`POST`** `https://api-datahub.bazhuayu.com/v1/data-apps/batch/settings`

认证：需要 API Key（`Authorization: Bearer <API Key>`）。

整簇 App 的可逆运营开关：上游变更或限流时，用同一条 `pause_message` 一次暂停所有相关 App，修好后一次恢复；批量切换可见范围同理（与批量授权配合，按「先填名单，再切到 shared」的顺序）。字段语义与单个 App 的设置端点完全相同，本端点只是把一份补丁应用到多个 App。

<ParamField body="app_names" type="string[]" required>
  —

### 示例请求

```bash
curl -X POST \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"apps": ["carol/reviews-query", "carol/product-detail"], "patch": {"accepting_runs": false, "pause_message": "上游限流，暂停服务"}}' \
  "https://api-datahub.bazhuayu.com/v1/data-apps/batch/settings"
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
