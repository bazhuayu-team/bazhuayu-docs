## 端点

```
PUT https://api-datahub.bazhuayu.com/v1/data-apps/{app_id}/grants/{username}
```

认证：需要 API Key，且仅 App 作者（发布者本人）可调用；其他人得到 `404`。

向指定用户开放该 App（幂等）。只在 `scope=shared` 时生效；名单内的用户可以查看和运行该 App，并按其价格计费（谁运行谁付费）。接口接受用户名，存储的是用户标识，因为用户名可变，不是标识符。

## 请求

### 路径参数

<ParamField path="app_id" type="string" required>
  App 引用。
</ParamField>

<ParamField path="username" type="string" required>
  被授权用户的用户名。
</ParamField>

### 示例请求

```bash
curl -X PUT \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/data-apps/carol/reviews-query/grants/dave"
```

## 响应

### 200 成功

```json
{
  "data": {
    "ok": true
  }
}
```

响应包在 `data` 字段中，其内容如下。

<ResponseField name="ok" type="boolean">
  固定为 `true`。
</ResponseField>

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误">错误</a>。
