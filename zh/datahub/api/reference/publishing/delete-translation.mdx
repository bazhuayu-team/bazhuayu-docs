---
title: "删除一种语言的译文"
description: "删除某种语言的译文 overlay，幂等。"
---

**`DELETE`** `https://api-datahub.bazhuayu.com/v1/data-apps/{app_id}/translations/{locale}`

认证：需要 API Key，且仅 App 作者（发布者本人）可调用；其他人得到 `404`。

幂等：删除不存在的语言仍返回 `200`，`deleted` 为 `false`。检索侧在本副本立即生效，其他副本随水位跟进。

## 请求

### 路径参数

<ParamField path="app_id" type="string" required>
  App 引用。
</ParamField>

<ParamField path="locale" type="string" required>
  语言代码。
</ParamField>

### 示例请求

```bash
curl -X DELETE \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/data-apps/carol/reviews-query/translations/en"
```

## 响应

### 200 成功

```json
{
  "data": {
    "deleted": false
  }
}
```

响应包在 `data` 字段中，其内容如下。

<ResponseField name="deleted" type="boolean" required>
  是否真的删除了一份译文。
</ResponseField>

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误">错误</a>。
