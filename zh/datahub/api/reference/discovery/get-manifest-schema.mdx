---
title: "manifest 规范（JSON Schema）"
description: "读取平台用于校验 manifest 的 JSON Schema 原文。"
---

**`GET`** `https://api-datahub.bazhuayu.com/v1/data-apps/manifest-schema`

认证：无需认证，可匿名调用。

manifest 规范（spec 0.2）的机读形式，JSON Schema 2020-12。返回的就是平台校验时使用的那一份，规范即实现，文档里不再另抄字段表。

供编辑器、编码助手和第三方校验器使用。对错判定唯一以 <a href="/zh/datahub/api/reference/publishing/validate-manifest">校验 manifest</a> 的返回为准。

## 请求

### 示例请求

```bash
curl \
  "https://api-datahub.bazhuayu.com/v1/data-apps/manifest-schema"
```
