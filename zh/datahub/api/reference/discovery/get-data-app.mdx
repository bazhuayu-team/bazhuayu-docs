## 端点

```
GET https://api-datahub.bazhuayu.com/v1/data-apps/{app_id}
```

认证：可匿名调用；携带 API Key 时可使用登录态才有的筛选或看到更多内容。

自包含的机读详情：输入契约与输出结构（JSON Schema）、执行模式、价格、使用知识、输入示例，以及 MCP / REST / CLI / SDK 四种调用示例。默认返回最新版本，传 `version` 可读取历史版本的契约。

可见性与运行门相同：公开 App 匿名可读；私有 App 仅作者可读；分享 App 仅授权名单内可读。不可见与不存在都返回 `404`，不暴露存在性。

## 请求

### 路径参数

<ParamField path="app_id" type="string" required>
  App 引用，`app_<hex>` 或 `<namespace>/<app_name>`。
</ParamField>

### 查询参数

<ParamField query="version" type="string">
  指定版本号读取历史契约，默认最新版本。
</ParamField>

### 示例请求

```bash
curl \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/data-apps/carol/probe-b"
```

<ResponseField name="app_id" type="string">

<ResponseField name="input_schema" type="object">

<ResponseField name="output_schema" type="object">

<ResponseField name="examples" type="object[]">

</ResponseField>

<ResponseField name="call_examples" type="object">
  渲染好的四种调用示例（`mcp` / `api` / `cli` / `sdk`）。
</ResponseField>

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `app-not-found` | `not_found` | App 不存在、已改名，或对当前凭证不可见（私有 / 分享范围之外）。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误">错误</a>。
