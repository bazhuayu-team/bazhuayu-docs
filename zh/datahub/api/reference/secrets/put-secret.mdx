## 端点

```
PUT https://api-datahub.bazhuayu.com/v1/secrets/{name}
```

认证：需要 API Key（`Authorization: Bearer <API Key>`）。

写入密钥值，已存在则覆盖，即轮换。名称是 manifest `runtime.env` 里引用的那个。

## 请求

### 路径参数

<ParamField path="name" type="string" required>
  密钥名称，大写字母、数字与下划线。
</ParamField>

### 请求体

<ParamField body="value" type="string" required>
  密钥明文。只写不读。
</ParamField>

### 示例请求

```bash
curl -X PUT \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"value": "sk-example"}' \
  "https://api-datahub.bazhuayu.com/v1/secrets/EXAMPLE_API_KEY"
```

## 响应

### 200 成功

```json
{
  "data": {
    "name": "EXAMPLE_API_KEY",
    "masked": "********mple",
    "scope": "publisher",
    "created_at": "2026-09-15T07:45:42.285442+00:00",
    "updated_at": "2026-09-15T07:45:42.285442+00:00"
  }
}
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误">错误</a>。
