## 端点

```
GET https://api-datahub.bazhuayu.com/v1/datasets/{dataset_id}/records
```

认证：需要 API Key（`Authorization: Bearer <API Key>`）。

分页读取数据集记录，参数与<a href="/zh/datahub/api/reference/runs/get-run-records" target="_blank" rel="noopener noreferrer">读取运行结果</a>相同；归属门与数据集详情相同，不可见即 `404`。

## 请求

### 路径参数

<ParamField path="dataset_id" type="string" required>
  数据集标识。
</ParamField>

### 查询参数

<ParamField query="offset" type="integer" default="0">
  分页起点。

范围 ≥ 0。
</ParamField>

<ParamField query="limit" type="integer" default="100">
  每页条数，最大 10000。

范围 1 到 10000。
</ParamField>

<ParamField query="format" type="string" default="json">
  输出格式。`json` 带信封与分页；`jsonl` 每行一条；`csv` 表格。

取值：`json` / `jsonl` / `csv`。
</ParamField>

<ParamField query="fields" type="string">
  逗号分隔的字段名，只返回这些列。
</ParamField>

### 示例请求

```bash
curl \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/datasets/ds_0bd5345d13d0/records?offset=0&limit=100"
```

## 响应

    "dataset_id": "ds_0bd5345d13d0",
    "records": [
      {
        "review_id": "103c9e-0000"
      },
      {
        "review_id": "103c9e-0001"
      }
    ],
    "partial": false,
    "pagination": {
      "offset": 0,

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `dataset-not-found` | `not_found` | 数据集不存在、不属于当前账号，或是平台公共样例集（不可标记）。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误" target="_blank" rel="noopener noreferrer">错误</a>。
