## 端点

```
GET https://api-datahub.bazhuayu.com/v1/datasets/{dataset_id}
```

认证：需要 API Key（`Authorization: Bearer <API Key>`）。

数据集元信息。别人的数据集与不存在的数据集返回同样的 `404`。

## 请求

### 路径参数

<ParamField path="dataset_id" type="string" required>
  数据集标识。
</ParamField>

### 示例请求

```bash
curl \
  -H "Authorization: Bearer $BAZHUAYU_API_KEY" \
  "https://api-datahub.bazhuayu.com/v1/datasets/ds_0bd5345d13d0"
```

### 错误

| HTTP | `code` | `category` | 说明 |
| --- | --- | --- | --- |
| 401 | `unauthorized` | `forbidden` | 缺少或无效的 API Key。 |
| 404 | `dataset-not-found` | `not_found` | 数据集不存在、不属于当前账号，或是平台公共样例集（不可标记）。 |

错误响应统一为 `{"error": {code, category, message, retryable}}`，见<a href="/zh/datahub/api/reference/introduction#错误" target="_blank" rel="noopener noreferrer">错误</a>。
