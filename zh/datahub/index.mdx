DataHub 是八爪鱼面向 AI 与业务场景的数据能力平台。它将采集模板、采集脚本、存量数据库、第三方数据接口和数据处理程序统一封装为标准化的 **Data App**，让人可以在线体验，让 Agent 和业务系统能够按需发现、理解并调用数据能力。

## 为什么需要 DataHub

过去，数据产品主要服务于人：浏览网站、下载报表、整理结果。现在，AI Agent 也需要直接使用外部数据。它们需要的不是人工阅读后再转述的页面，而是能够被机器理解、结构化调用和按量计费的数据服务。

DataHub 从这一变化出发设计：人可以用，Agent 更好用。使用者无需为每一个数据源单独寻找供应商、编写采集脚本或适配不同接口；数据能力以统一方式被发现和调用。

## DataHub 如何工作

<img src="/assets/datahub/standardized-data-app-flow.png" alt="不同数据来源经标准化封装为 Data App，再通过网站门户、API、MCP 或 SDK 服务于 Agent、业务系统和用户" />

无论底层来自网页采集、已有数据集、第三方接口还是数据清洗程序，DataHub 都以 Data App 作为统一产品形态。数据能力可以持续增加，而使用者的接入方式保持稳定。

## 什么是 Data App

Data App 是 DataHub 上可被发现和调用的一项数据能力，可以理解为平台上的“商品”。例如，按关键词获取新闻内容、查询商品评论、获取视频详情，或对文本做数据处理，都可以被封装为一个 Data App。

<img src="/assets/datahub/data-app-anatomy.png" alt="Data App 包含发布者和应用名、机器可读说明、输入输出字段、公开价格与在线体验入口" />

| 要素 | 说明 |
| --- | --- |
| **发布者 / 应用名** | Data App 的唯一标识，便于定位具体能力与提供方。 |
| **机器可读说明** | 描述用途、输入参数、输出字段和使用边界，供 Agent 或系统理解。 |
| **标准输入输出** | 以结构化参数发起调用，并获得结构化结果。 |
| **在线体验** | 登录后可先试跑真实数据，确认效果后再接入流程。 |
| **公开价格** | 在详情页展示计费规则，按应用实际使用情况结算。 |

## 按量计费

DataHub 采用按量结算：可以先浏览和体验，实际调用后再按 Data App 详情页公开的规则计费。不同应用的价格由发布者设定，常见计费方式包括：

- **起步价**：每次提交任务收取固定费用，与返回条数无关。
- **按条计费**：按成功返回的数据条数结算；也可以按固定条数打包为一个计费单位。
- **自定义单位**：针对特定能力按适合的单位计费，例如分钟音频。

任务失败不产生数据费用；部分成功则按实际成功返回的数据结算。费用从账户余额中扣除，余额不足时会阻止新的调用；使用者可在开放平台控制台核对用量与账单。
