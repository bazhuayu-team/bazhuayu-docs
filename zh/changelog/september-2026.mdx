# 全站文档可读性与媒体兼容性治理

> **文档同步日期：** 2026 年 9 月 17 日

已完成中文文档站 932 篇页面的结构化可读性扫描与修复，其中包含本次从主分支同步的 Data Hub API 文档。具体包括：

- 清理 38 处独立反斜杠占位、旧编辑器遗留的不可见空白、27 个空标题和 123 处异常行尾转义。
- 修正图片被误用为标题、微博案例页嵌套链接、旧式 URL 转义等影响正文渲染的问题。
- 将腾讯云视频资源统一从 HTTP 升级为 HTTPS，避免正式站出现混合内容拦截。
- 为 155 篇缺少摘要的教程、案例、视频与 OpenAPI 页面补充 `description`，改善搜索摘要和标题检索表现。
- 同步主分支新增的 Data Hub API 文档，并统一其中 60 篇页面的正文链接打开方式与安全属性。
- 校验全站 1,808 个本地静态资源引用，未发现缺失图片或资源文件。
- 复核正文链接及 541 篇隐藏知识库页面，链接审计与知识库校验均已通过。

项目新增 `npm run docs:readability:check` 与 `npm run docs:readability:fix`，后续新增或迁移文档时可重复执行，及时发现同类排版问题。

# 站内搜索优化与知识库排除

> **文档同步日期：** 2026 年 9 月 8 日

站内搜索的候选索引范围已扩展至正式文档页面，修复部分未列入导航清单的分类页和入口页无法被搜索到的问题。采集学院、安装注册、三分钟快速上手、常见问题、视频专区、计费与套餐等核心页面补充了中文同义词关键词，并提高“快速入门”“操作指南”等重点内容的搜索权重。

知识库 FAQ 页面继续保留原有直达链接和 Agent 知识索引，但全部设置为 `hidden` 与 `noindex`，不参与 Mintlify 站内搜索、MCP/AI 文档索引及搜索引擎收录。知识库导入脚本已同步这一规则，后续重新导入时不会将知识库内容重新纳入文档搜索。

> 发布后 Mintlify 会重新建立线上搜索索引；可通过搜索“Windows安装”“注册账号”“创建任务”“价格”“免费试用”等词复核核心页面命中情况。
