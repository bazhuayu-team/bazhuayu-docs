# 八爪鱼采集器 MCP 工具与工作流同步

> **文档同步日期：** 2026 年 8 月 28 日

八爪鱼采集器 MCP 当前主入口实测公开 12 个工具。文档新增 [`get_task_status`](/zh/mcp/get-task-status) 和 [`describe_ecommerce_dataset`](/zh/mcp/describe-ecommerce-dataset) 页面，并将模板云采集主流程更新为：`search_templates` 精确读取实时模板契约 → `execute_task` 自动检查并启动 → `get_task_status` 获取状态与 `lotNo` → `export_data` 分页读取或使用签名链接下载。

同步修正了模板搜索的 `query` 参数和 `sourceTree` 选项规则、导出的 `taskId + lotNo + page/pageSize` 契约，以及 Temu / TikTok Shop 从任务提交、结果集描述到查询的流程。客户端验证、Coze / Dify 提示词、速率限制与故障排查不再将 `validateOnly`、MCP Tasks 或旧导出字段描述为当前接口。

# CLI v0.1.33

> **更新日期：** 2026 年 8 月 7 日
> 当前安装版本：`bazhuayu-cli@0.1.33`

```bash
npm install -g bazhuayu-cli@0.1.33
bazhuayu --help
```

本次更新重写了 `bazhuayu --help`：命令按 Create、Run、Manage、Data 和 Config 分类展示，发布版不再在帮助中暴露 `env`、`runs` 等内部开发命令。`bazhuayu capabilities --help` 现在只显示帮助文字；Agent 和自动化流程应继续使用稳定的 `bazhuayu capabilities --json` 读取机器契约。

模板市场同步更新：搜索结果按公开 `templateId` 全局去重并在去重后分页，同一模板的多语言记录只保留排序靠前的名称；总数表示唯一模板数量。CLI 参数、帮助和公开 JSON 输出统一使用 `templateId`，新脚本不应再使用 `--template-registration-id`，也不应依赖 `templateRegistrationId`、`status`、`raw` 等内部字段。后端所需的注册 ID 映射由 CLI 在内部处理。

`task list` 新增 `--status`、`--task-type` 和 `--scheduled true|false` 筛选，可与 `--template-id`、关键词和任务组筛选组合使用。相关文档：<a href="/zh/cli/index" target="_blank" rel="noopener noreferrer">CLI 概述</a>、<a href="/zh/cli/quick-start/installation" target="_blank" rel="noopener noreferrer">安装与验证</a>、<a href="/zh/cli/core-commands/task-management" target="_blank" rel="noopener noreferrer">任务管理</a>、<a href="/zh/cli/reference/command-cheatsheet" target="_blank" rel="noopener noreferrer">命令速查表</a>。

# OpenAPI 支持 API Key 认证

> **文档同步日期：** 2026 年 8 月 3 日

OpenAPI 业务接口现补充 API Key 授权说明。调用时在请求头中传入 `x-api-key: op_sk_xxxxxx`；API Key 与 MCP 使用同一套密钥，可在八爪鱼官网账户中心创建。

交互式 OpenAPI 界面现声明 `x-api-key` 的 API-key security scheme，并保留既有 Access Token 作为兼容认证方式。每个请求只需选择其中一种，不要把 API Key 写成 Bearer Token，也不要将真实密钥提交到代码、截图或日志中。
