# DataHub 千问办公与 WorkBuddy 内置连接器上线

> **文档同步日期：** 2026 年 10 月 9 日

八爪鱼 DataHub 已在千问办公和 WorkBuddy 上线内置连接器。在 Agent 的连接器市场中找到对应连接器，完成 OAuth 账号授权后，即可在对话中使用 DataHub，无需手动填写 MCP 地址或 API Key。

- 新增<a href="/zh/datahub/quick-start/agent-connection/qwen-office-connector" target="_blank" rel="noopener noreferrer">千问办公：内置连接器</a>教程，说明搜索「八爪鱼Data Hub」、安装连接器、账号授权与连接状态确认。
- 新增<a href="/zh/datahub/quick-start/agent-connection/workbuddy-connector" target="_blank" rel="noopener noreferrer">WorkBuddy：内置连接器</a>教程，说明搜索「DataHub」、完成授权，以及在具体对话中启用连接器。
- 补充搜索 Data App、核对输入参数、确认计费、发起运行、查询状态与读取结果的使用说明，并提供操作截图和常见问题。
- 更新 DataHub 概览、MCP 能力说明及相关接入教程，区分平台内置连接器、通用 MCP 连接和指定 App 连接，保留原有手动配置方式。

本次新增的是 DataHub 连接器教程；八爪鱼采集器 MCP 的千问办公与 WorkBuddy 接入说明已记录在<a href="/zh/changelog/september-2026" target="_blank" rel="noopener noreferrer">9 月更新日志</a>中，两者分别服务于 Data App 与采集器任务操作。

# DataHub 网页端直接使用教程调整

> **文档同步日期：** 2026 年 10 月 9 日

DataHub 快速入门页面统一命名为<a href="/zh/datahub/quick-start/client-use" target="_blank" rel="noopener noreferrer">网页端直接使用</a>，明确这是在浏览器中直接使用 DataHub 的流程，不需要安装客户端、配置 MCP 或编写代码。

教程按“访问并登录 DataHub → 选择并了解 Data App → 在线运行并检查结果 → 完成检查”组织，说明输入参数、结果字段、计费方式及结果读取和导出。页面移除 Agent 连接方式卡片和“下一步：连接 Agent”章节，保持网页使用与 MCP 接入两条路径独立。

DataHub 概览、左侧导航及历史日志中的相关入口名称同步更新。

# 首页与 DataHub 文档入口调整

> **文档同步日期：** 2026 年 10 月 9 日

<a href="/zh/overview" target="_blank" rel="noopener noreferrer">文档站首页</a>补充 DataHub 的产品定位、Data App 使用流程及入门入口，明确区分采集器的任务采集流程与 DataHub 的数据能力使用方式。

DataHub 快速入门分别提供网页端直接使用和 MCP 连接使用入口；MCP 导航中的“国内 Agent 内置连接器”位于通用连接、Codex 指定 App 与 WorkBuddy 指定 App 教程之后，便于按使用方式查找教程。DataHub 概览同步梳理网页、Agent 和 API / SDK 的使用路径，并补充国内 Agent 连接器入口。
